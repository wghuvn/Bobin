Bobin Craft 2.7.7 — экспериментальный патч медленной загрузки лесного хаба

Изменения в 3 Java файлах:
- HubChunkGenerator: вычислять высоту рельефа и уровень воды один раз на (x,z) при генерации чанка и запросе колонки, без изменения алгоритма terrainState.
- HubForestDecorator: кэш высот в пределах текущего вызова decorate, без общей памяти между потоками.
- RaidManager: диагностические записи [Bobin load] перед и после первичного строительства хаба.

Сохранена регистрация fabric.mod.json из предыдущего metadata patch.
Код не компилировался и не тестировался в Minecraft в среде генерации патча.
Если мир всё ещё висит на 100%, прислать .minecraft/logs/latest.log (после зависания, до следующего запуска игры).
Сначала сделайте резервную копию saves. Не открывайте оригинальные старые миры ради эксперимента.
Этот патч не исправляет возможные проблемы совместимости старых сохранений.

Bobin Craft 2.7.7 — исправление FPV-загрузки чанков (Minecraft 1.20.1 / Fabric / Yarn build.10)

Файлы заменяются ОТНОСИТЕЛЬНО КОРНЯ проекта Bobin_craft.
Сделайте резервную копию текущего проекта, распакуйте патч с заменой 5 файлов.

Изменения:
- DroneChunkStreamer: загрузка дальних чанков по ticket API; предзагрузка по полёту,
  ограничение количества запросов и сетевых отправок, сдвиг центра обзора,
  восстановление после завершения управления и очистка билетов.
- DroneEntity: удалена синхронная генерация чанков из тика дрона. Пока следующий
  чанк не готов, дрон останавливается у границы, а не рвёт сессию.
- DroneNetworking: подключён запуск/завершение стриминга и END_SERVER_TICK.
- DroneEntityTrackerMixin: владелец продолжает получать штатные entity-пакеты
  своего управляемого дрона вне обычного расстояния отслеживания.
- bobin_craft.mixins.json: регистрация нового Mixin.

ВАЖНО: Третий параметр ServerChunkManager.addTicket в Minecraft 1.20.1 —
радиус, НЕ уровень! Значение 2 для активного дрона даёт уровень 31;
значение 0 для FULL-чанка — уровень 33. Не заменяйте их на 31/33.

Сборка в Windows из корня проекта:
    gradlew.bat build -x test

Запускайте на реальном мире сначала с резервной копией сохранения.
Проверьте: полёт дальше обычного view distance, генерацию новых чанков,
возврат камеры к игроку, переподключение, полёт двух игроков одновременно.

Ограничение проверки: удалось выполнить статические проверки связей и JSON.
Полная сборка и запуск Minecraft НЕ выполнялись: в среде сборки отсутствует
скачанный Gradle 8.8 и закрыт доступ к services.gradle.org.

Текущий патч передаёт чанки и штатно отслеживает САМ дрон; он не добавляет
полную удалённую симуляцию всех мобов и NPC и не заменяет штатную систему
рассылки изменений блоков/сущностей для удалённой камеры.

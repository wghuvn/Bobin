Bobin Craft 2.7.7 — восстановление регистрации мода / выбора типа мира

ИСПРАВЛЕНО:
* Добавлен отсутствовавший src/main/resources/fabric.mod.json.
* Описаны точки входа мода BobinCraft и BobinCraftClient.
* Подключён существующий bobin_craft.mixins.json.
* Сохранены исходные пресет bobin_craft:warzone, мировые генераторы и переводы.

НЕ МЕНЯЛОСЬ:
* Камера по G, старое оружие, система осады НЕ возвращались.
* Никакие старые миры, чанки, NBT, рейды или структуры не пересоздавались.

КАК УСТАНОВИТЬ:
1. Сделайте резервные копии папки проекта и папки saves.
2. Распакуйте этот архив, чтобы получить Bobin_craft/.
3. В папке Bobin_craft выполните gradlew.bat clean build -x test.
4. Используйте build/libs/bobin_craft-2.7.7.jar (НЕ -sources.jar).
5. Уберите предыдущие версии bobin_craft*.jar из папки mods.
6. Убедитесь, что установлены Minecraft 1.20.1, Fabric Loader и Fabric API.
7. Проверьте список модов, новый мир (выбор типа Bobin_craft) и КОПИЮ старого сохранения.

ОГРАНИЧЕНИЯ ПРОВЕРКИ:
* Проверена структура ZIP, JSON, классы точек входа и привязки к пресетам.
* Компиляция Gradle и запуск Minecraft в текущем окружении не выполнены.
* Если в вашем локальном проекте fabric.mod.json уже был, одного этого исправления
  может быть недостаточно. Нужны latest.log и точный используемый JAR.
* В старых хабах RaidManager отключает рейды, если сохранённая схема хаба
  не совпадает с текущей версией 4. Эта проверка не должна мешать загрузке мира.

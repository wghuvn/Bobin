# Bobin Craft 1.8.1

Установите `bobin_craft-1.8.1.jar` вместо предыдущего JAR на клиентах и сервере.
Версия Minecraft — 1.20.1, Java 17, Fabric Loader 0.15.11+ и соответствующий Fabric API.

- У бомбера и FPV полностью убраны красные автоматические рамки NPC и поиск
  сущностей для их отрисовки. Обычный неподвижный прицел и телеметрия остаются.
- Картинка камеры немного пикселизирована уже при хорошем сигнале. Для Full HD
  используется видеокадр 1280 × 720 с увеличением ближайшими пикселями. Надписи HUD
  рисуются отдельно и остаются чёткими. Сглаживающее размытие не добавлено.
- Помехи мельче и многочисленнее: размер базового фрагмента около ширины GUI / 160
  вместо / 45, максимум 240 вместо 56. Толстая полоса заменена несколькими короткими
  тонкими штрихами. Цвет помех чёрно-серый.

На небольших окнах детализация также немного снижается: не более 85% исходного
размера по каждой оси, с сохранением пропорций. На слабом сигнале детализация
понижается ступенями 1280 / 960 / 720 / 480 по длинной стороне. Базовая пикселизация
есть и при полной связи; полоски сигнала показывают качество связи отдельно.

Дальность, плавное ослабление сигнала, запас на краткие провалы связи, управление,
положение камер, разные сбросы, урон и сохраняющиеся следы версии 1.8.0 сохранены.

Сборка и 25 проверок прошли. Графический клиент здесь не запускался. В игре следует
проверить вид из обеих камер, отсутствие рамок вокруг NPC, читаемость HUD и более
мелкие частые помехи при отдалении или за толстым укрытием.

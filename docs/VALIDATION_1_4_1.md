# Bobin Craft 1.4.1 — проверка обновления

Изменено управление дроном: по умолчанию включена помощь в полёте, повороты мышью,
движение WASD, подъём E/↑ и снижение Q/↓. Отпускание клавиш включает торможение
и удержание координат и высоты. У FPV сохранён дополнительный ручной режим.

Сброс бомбера исправлен: заряд появляется полностью ниже корпуса, наследует его
движение и взводится после отделения. Низкий или перекрытый сброс отклоняется без
расхода боезапаса. Дрон остаётся уязвимым для обычного игрового урона.

## Выполненные проверки

- **22 теста дронов прошли, ошибок 0, пропусков 0.** Проверены зависание
  при повороте камеры, торможение и возврат к точке удержания, сохранение высоты
  бомбера при движении и направление FPV вслед за обзором.
- Взлёт и мягкая посадка обоих дронов проверены с настоящим обработчиком коллизий
  Minecraft на плоском полу; обычное снижение не достигает порога аварии.
- Проверены ограничение скорости, отключение моторов, ввод, последовательности
  пакетов, потеря управления, сигнал и условия взведения отделившейся бомбы.
- Все production-исходники скомпилированы для Java 17 / Minecraft 1.20.1,
  Yarn 1.20.1+build.10 и Fabric API 0.92.2+1.20.1.
- Аудит production-байткода: `MIXIN_REMAP_PASS mixins=12 selectors=16 shadows=4 invocationTargets=3`.
- Ресурсы дронов: три предмета, рецепты и модели, текстуры, 52 ссылки на переводы
  и шесть имён проверены в английской, русской и украинской локализациях.
- Проверка генератора изображений и целостности выходных архивов пройдена.

Полный набор из 163 тестов прошёл для предыдущей версии 1.4.0. Неизменённые
проверки генерации мира повторно не запускались в этом обновлении дронов.

## Ограничения проверки

Живой сеанс Minecraft с новой схемой управления не проводился. Комфорт мыши,
ощущение управления и сетевые задержки требуют проверки в игре. Статическая
проверка захвата мыши выполнена по коду Minecraft; курсор освобождается при
выходе из управления и потере фокуса.

Существовавшая в исходном архиве проблема 14 таблиц старого лута с неизвестными
предметами сохранена и описана в `VALIDATION_1_4_0.md`. Эти таблицы не относятся
к новым ресурсам дронов; целевой валидатор дронов проходит.

На клиенте и сервере нужна одинаковая версия 1.4.1: пакет управления расширен
для передачи направления обзора. Старый JAR следует заменить, оставив одну
версию Bobin Craft в папке mods.

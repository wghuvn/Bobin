# Bobin Craft 1.4.4 — сброс бомбера на ЛКМ

Сброс перенесён с F на левую кнопку мыши в DroneScreen.java. Один клик ставит
одну команду сброса; удержание не создаёт непрерывного сброса. Клавиши F и пробел
не сбрасывают бомбы. Пробел сохраняет подъём.

Сброс доступен только в активном режиме полёта с захваченным курсором и фокусом
окна. Alt включает работу с кнопками интерфейса; такой клик не сбрасывает бомбу.
ПКМ, потеря фокуса, отпущенный курсор и начатая отвязка также не запускают сброс.
Сохранены проверки бомбера, работающих моторов, высоты и оставшегося боезапаса.
Подсказки обновлены на английском, русском и украинском языках.

## Проверка

**Все 37 целевых тестов прошли: ошибок и пропусков нет.**

Результат целевых тестов записан в test-run-144.log рабочего каталога.
Проверяются полёт, зависание, столкновения, подрыв заряда, сессии и обработчик
кликов. Обновлённые проверки ввода вызывают рабочий обработчик клика с заданным
состоянием фокуса и курсора, без создания графического окна. Проверяются также
F/пробел без сброса, сохранение очереди при закрытии экрана, Alt, ПКМ, потеря
фокуса, малое расстояние до земли и блокировка при отвязке.

Production-сборка использует Java 17 / Minecraft 1.20.1 и кешированные зависимости
проекта. Ресурсы дронов и переводов проверяются отдельным валидатором, архивы —
при упаковке. Живой Minecraft не запускался; для проверки ощущений нужен игровой
сеанс. Тесты генерации мира повторно не запускались.

## Установка

Замените прежний Bobin Craft в mods на bobin_craft-1.4.4.jar. Оставьте одну версию
мода. Для сетевой игры обновите клиент и сервер; новый мир не нужен.

Для ручной замены исходника используйте приложенный DroneScreen.java и заново
соберите проект. ЛКМ сбрасывает одну бомбу, Alt + ЛКМ работает с интерфейсом.

## Независимость FPS и общая семантика

`PresentationAction` расширен действием AIM. `SharedPresentationActions`
добавляет его к общему диагностическому источнику действий и времени.
Команда `tp anim aim` использует существующий FPS idle как визуальное
представление первого лица. Нового FPS ADS нет: это сознательное сохранение
утверждённого первого лица, а не копирование 3P-поз в FPS.

Мост `PairedPresentationLifecycleMixin` передаёт только действие/время и
оставляет старые проверки пригодности. Логика `FirstPersonWeaponPresenter`,
`FirstPersonDiagnostic`, FPS hand setup и FPS-клипы не редактировались.
Действие AIM удерживается при F5; новый legacy action/static или потеря
пригодности явно снимают aim-намерение. Ресурсная перезагрузка сохраняет старое
поведение FPS: при замене его bundle возможен переход в калибровку; aim после
такой перезагрузки включается повторной командой.

Семантические времена прежних пяти действий сохранены. После окончания inspect
общая семантика уже IDLE, а отдельная 3P-презентация ещё завершает осмотр через
hold/recovery. Новый ввод может прервать эту фазу с текущей позы. Так более
длинное внешнее движение не меняет таймеры или анимацию первого лица.
Вес следования за взглядом также плавно меняется при входе/выходе aim, чтобы
смена состояния не вызывала мгновенного поворота предмета при ненулевом yaw/pitch.

## Привязка тела

`ThirdPersonBodyFrame` несёт опору нижней части тела и фазу шага. Ноги и их
анимации остаются vanilla; корпус не заменяет нижнюю половину персонажа.
Слой движения получает фазу `limbAnimator.getPos(delta) * 0.6662 / (2π)`,
согласованную с vanilla Biped gait. Ключи движения больше не поднимают верхнюю
часть тела отдельным вертикальным циклом.

Нижняя грань торса имеет полуразмеры 4×2 пикселя. Её необходимое погружение
в ноги вычисляется из текущей матрицы вращения, а не задаётся произвольным
офсетом приседания. Голова и hat следуют за перемещением шеи, сохраняя vanilla
look и небольшой отдельный 3P head assist. После рендера восстанавливаются
body, руки, jacket/sleeves, head/hat. Геометрия, UV и skin-part visibility
не заменяются. Обычные предметы по-прежнему выключают диагностическую позу.

Blender-файлы содержат авторские клипы. Runtime дополнительно применяет
constraint хвата, текущую опору vanilla-ног и геометрическое перекрытие талии.
PNG-превью учитывают перекрытие талии; они отдельно помечены как Blender,
а игровые снимки лежат в другом каталоге.

## Повторение

1. Заменить прежний Bobin JAR единственным новым JAR; внутренняя версия мода
   остаётся `2.7.7-clean`. Запустить Fabric 1.20.1 / Java 17 с
   `-Dbobin.armament.glbDebug=true` либо `./gradlew runGlbDebugClient`.
2. Здоровый игрок, пустые руки, обычная камера. Выполнить `/bobin_glb tp show`, затем
   `/bobin_glb tp anim aim`. Проверить F5 сзади и спереди, повороты головы,
   ходьбу, sprint, crouch и прыжки.
3. По очереди `tp anim idle|move|raise|lower|inspect|aim` и `tp status`.
   У inspect дождаться `end_hold`, `inspect_recover`, затем idle.
   Прервать осмотр aim и наоборот. Контролировать отсутствие скачка позы.
4. Проверить боковой ракурс, оба варианта скина, рукава/броню, F3+T,
   обычный предмет и восстановление после `tp hide` / `fp hide`.
   Первое лицо должно остаться визуально прежним.

Из корня проекта:

```sh
./gradlew --no-daemon --max-workers=4 build
./gradlew --no-daemon --max-workers=4 -p tools/armament-glb-check test
blender -b -t 4 --python scripts/armament/export_third_person_fixture.py -- --variant default --render
blender -b -t 4 --python scripts/armament/export_third_person_fixture.py -- --variant slim --render
blender -b -t 4 --python scripts/armament/render_third_person_views.py
```

FPS exporters для этого этапа запускать не требуется.

# Task 5.1.3 — проверка в Minecraft

Это инструкция для проверки, а не свидетельство выполненного игрового теста.
Нужны Java 17, Minecraft 1.20.1, Fabric Loader 0.15.11 и Fabric API 0.92.2+1.20.1.
Полная Gradle-сборка требует доступного `https://maven.fabricmc.net`.

1. Собрать `./gradlew --no-daemon --max-workers=4 build` и запустить
   `./gradlew runGlbDebugClient` (включает `-Dbobin.armament.glbDebug=true`).
2. Создать локальный тестовый мир. Перейти в первое лицо; обе руки пустые,
   персонаж здоров, не управляет дроном/техникой и не находится в несовместимом режиме.
3. Выполнить `/bobin_glb fp show`, затем `/bobin_glb fp static`.
   В `/bobin_glb fp status` должен быть `staticIdle=true`.
4. При одинаковом разрешении проверить FOV 70/90/110, затем 4:3/16:9/21:9.
   Проверить размер правого предплечья, непрерывный силуэт от края кадра,
   сгиб левого локтя, стороны больших пальцев, просветы и проникновения.
   Центральная зона должна оставаться свободной. Сравнивать с присланным
   пользователем FPS-референсом, учитывая нейтральную геометрию стенда.
5. `/bobin_glb fp diagnose` печатает последнее успешно показанное положение:
   координаты и глубины суставов в метрах камеры, углы локтей, непрерывные
   NDC-границы мешей и ошибки sockets. NDC-границы не равны площади видимого
   силуэта; socket error не заменяет проверку поверхности пальцев.
6. По очереди выполнить:

   ```text
   /bobin_glb fp anim idle
   /bobin_glb fp anim inspect
   /bobin_glb fp anim raise
   /bobin_glb fp anim lower
   /bobin_glb fp anim move
   ```

   Проверить движение пальцев/локтей, контакт с образцом и плавные переходы,
   в том числе быстрый `inspect → lower → raise → idle`, ходьбу и повороты.
   Сравнить при ограничении кадров 30/60/144 FPS. `inspect` удерживает образец
   обеими руками; отпускание и повторный захват не заявлены и не добавлены.
7. Проверить Steve и Alex, актуальный пользовательский скин, независимое
   отключение левого/правого рукава в настройках скина. Повторить после F3+T.
8. `/bobin_glb fp hide`: обычные предметы и vanilla-руки должны восстановиться.
   Без отладочного JVM-флага режим изначально выключен. Проверить сохранность
   прежних static GLB и animation preview через существующие `/bobin_glb`
   команды (их ветки не заменялись).

Blender-превью являются диагностическими рендерами исходных мешей, а не
скриншотами Minecraft. CPU-тесты проверяют импорт, матрицы, геометрию и
переходы; они не проверяют GPU, освещение мира, live skin или игровой ввод.

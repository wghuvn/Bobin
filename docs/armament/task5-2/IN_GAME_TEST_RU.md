# Игровая проверка этапа 5.2

Эта инструкция — план приёмки. Minecraft в облачной среде не запускался.
Прежде чем считать этап визуально принятым, нужны успешная полная сборка и
проверка на реальном клиенте Fabric 1.20.1 / Java 17.

1. Собрать проект: `./gradlew --no-daemon --max-workers=4 build`.
   Если Fabric Maven запрещён политикой среды, применить сохранённые домены
   в environment settings и повторить сборку. Готовый JAR сейчас не предоставлен.
2. Запустить `./gradlew runGlbDebugClient` либо клиент с
   `-Dbobin.armament.glbDebug=true` и обновлённым модом. Создать тестовый мир.
3. Локальный игрок здоров, не в транспорте, обе руки пусты. Сначала проверить
   утверждённое первое лицо через `/bobin_glb fp show`. Геометрия, хват,
   масштаб, клипы и камера должны соответствовать прежней версии.
4. Выполнить `/bobin_glb tp show`, затем F5. Команда включает парное
   диагностическое представление; при уже активном действии оно не сбрасывается.
5. По очереди запустить:

```text
/bobin_glb tp anim idle
/bobin_glb tp anim inspect
/bobin_glb tp anim raise
/bobin_glb tp anim lower
/bobin_glb tp anim move
/bobin_glb tp status
```

Inspect/raise возвращаются к idle по общей временной шкале; lower удерживает
конечную позу. Явный move включает отдельный цикл движения. Ходьба и sprint
также включают свой слой автоматически после выхода из статической калибровки.
`/bobin_glb fp static` возвращает статическую калибровку обеих презентаций.

6. Для каждого состояния осмотреть модель спереди, сзади и сбоку; повернуть
   персонажа на 360°. Проверить основную рукоятку и переднюю опору, устойчивые
   плечи, отсутствие масштабирования рук и прохода предмета сквозь торс.
   В inspect движения должны заметно отличаться от первого лица.
7. Ходьба вперёд/назад/вбок, sprint, crouch на месте и в движении, прыжки,
   остановка и поворот головы. Ноги сохраняют обычную Minecraft-анимацию;
   голова смотрит независимо, особенно во время inspect/lower.
8. Переключать обе внешние камеры F5 и первое лицо посреди inspect/raise/lower.
   Action/started в status не должны сбрасываться из-за камеры. Предмет не
   дублируется, не меняет физический размер и не отрывается от рук.
9. Повторить со Steve и Alex, своим скином, бронёй, каждым рукавом отдельно
   и скрытыми рукавами. UV и внешность остаются стандартными.
10. Нажать F3+T посреди действия и после его завершения. После загрузки
    оба варианта должны отрисоваться без белых/потерянных текстур и дубликатов.
    Проверить tpGeneration, отсутствие постоянного роста GLB textures и лог.
11. Взять обычный предмет в каждую руку по очереди, использовать/махнуть им.
    Диагностическая поза и предмет должны уступить обычному рендеру.
    После `/bobin_glb tp hide` обычные позы полностью восстанавливаются.
12. Отдельно проверить существующие гранаты, GROM-7, дрон, бронетехнику,
    травмы/ампутации/ползание, смерть/respawn, spectator, сон/плавание и
    отключение от мира. Диагностика не должна перехватывать их руки/камеру.
13. Проверить другого игрока: локальный диагностический режим не должен
    менять его модель. Сетевая демонстрация другим игрокам в этот этап не входит.

Завершение: `/bobin_glb tp hide`, затем `/bobin_glb fp hide`.
Баллистика, патроны, перезарядка, предмет оружия и NPC здесь не добавлены.

## Воспроизведение CPU и Blender

```sh
# Из корня проекта, JDK 17, Gradle wrapper 8.8.
./gradlew --no-daemon --max-workers=4 -p tools/armament-glb-check test
python3 scripts/verify_armament_schemas.py
python3 scripts/verify_first_person_schema.py
python3 scripts/armament/test_triangle_contacts.py
blender -b -t 4 --python scripts/armament/export_third_person_fixture.py -- --variant default --render
blender -b -t 4 --python scripts/armament/export_third_person_fixture.py -- --variant slim --render
```

Не запускать FPS-exporters для этого этапа. 3P exporter создаёт только новые
`third_person_fixture*` файлы. Внутри Blender сцены одноимённые NLA tracks
согласованы между узлами; для просмотра действия включать соответствующие
tracks на корпусе, предмете и руках. `move`/`run` добавляются к `idle` либо
действию, `crouch` — отдельный аддитивный posture слой. Preview-голова и ноги
служат только для схемы внешнего вида; в runtime работают исходные ModelPart.
